# יישומון ריבוע הקסם – פריזמה

יישומון סטטי מוכן ל-GitHub Pages.

## הפעלה
פתחו את `index.html` בדפדפן, או העלו את כל התיקייה ל-GitHub Pages.

## קבצים
- `index.html` – מבנה היישומון
- `styles.css` – עיצוב פריזמה ורספונסיביות
- `app.js` – לוגיקת המשחק, שלבים, רמזים ובדיקת תשובות
- `assets/` – לוגו ופונט Simpler Pro
