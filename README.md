# ריבוע קסם – תרגול חיבור מספרים מכוונים | פריזמה

משחק סטטי מוכן ל־GitHub Pages (שער עצמאות).

## מבנה
- `index.html` – מבנה המשחק, חלון עזרה עם דוגמה פתורה, רשימת תרגילים
- `styles.css` – עיצוב פריזמה ורספונסיביות
- `app.js` – מחולל לוחות (פתרון יחיד, מגבלות קושי), שלבים, רמזים, צלילים
- `assets/` – לוגו, אייקונים וצלילים מתיקיית prisma ב־Drive; פונט Simpler Pro

## שלבים
בכל רמה: 3×3 ← 4×4 ← 4×4 קשה יותר.
- לכל היותר 2 שורות/טורים עם מספר אחד בלבד (1 בלוח 3×3), לכל היותר שורה אחת של חיוביים בלבד.
- רמה מתקדמת: בכל לוח שברים פשוטים **או** עשרוניים (לא שניהם); בשלב הראשון 2–3 בלבד.
- לכל לוח פתרון יחיד; הבדיקה נעשית לפי הסכומים.
